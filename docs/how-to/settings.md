# Change settings and read Cleanups

Use this page to choose how many scans Disk Cleaner keeps and to read what agents asked for.

## Settings

Open Settings with the gear or Command-comma; it is a page in the same window, and Back or Esc returns. Choose whether to remember the last scan, and how many scans to keep: 5, 10 or 30.

## Cleanups

**Cleanups** lists past capacity requests from agents, with targets, measurements and outcomes. A `completed` result means the space was already available. No cleanup category is enabled, so a request for more space than exists answers `insufficient`.
