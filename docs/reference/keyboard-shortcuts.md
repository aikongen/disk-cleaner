# Keyboard shortcuts

Use this page to find the keys Disk Cleaner defines itself.

| Keys | What it does |
| --- | --- |
| Command-comma | Open Settings, a page in the main window. |
| Esc | Go back from Settings, or leave the Trash review without moving anything. |
| Command-question mark | Open this help. |

Everything else follows the standard Mac shortcuts, such as Command-Q to quit.
