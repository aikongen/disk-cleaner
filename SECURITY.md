# Security

Disk Cleaner is a local macOS app and command line tool. It can move files you select to the Trash. It never deletes permanently, and the command line tool cannot take paths or commands from a caller.

## Reporting a vulnerability

Report privately through GitHub: open the Security tab of aikongen/disk-cleaner and choose "Report a vulnerability" (private vulnerability reporting / security advisories). Please do not open a public issue for a vulnerability.
